# Spam Ham SMS Classifier

A Python machine learning project that classifies SMS messages as **spam** or **ham** (not spam).

## What It Does

- Reads SMS data from `Spam_SMS.csv`
- Displays a bar chart comparing spam and ham messages
- Uses `CountVectorizer` to process text
- Trains a Logistic Regression model
- Lets the user enter a message and predicts whether it is spam or ham

## Technologies Used

- Python
- pandas
- matplotlib
- scikit-learn
